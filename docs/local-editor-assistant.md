# Local page assistant and MCP

- Baseline `b1e2cdec33ff2fffc52828e42f692541588d8080`; separate limits: 1,000 new / 3,000 changed lines. No new test cases. Automatic MLS updates remain deferred.
- Put `EDITOR_AI_URL=http://host.docker.internal:4000/v1`, `EDITOR_AI_MODEL=openai-gpt-oss-120b-1-0`, and a LiteLLM virtual key as `EDITOR_AI_KEY` in ignored `.secrets/editor.env`. Rebuild the existing dev mirror using `compose.yaml` plus `compose.dev.yaml`. The assistant is enabled only for local/test environments with a localhost public origin. Provider secrets stay in backend configuration.
- Sign in at `/login`, enter edit mode, and choose Page assistant. Select a section, describe changes, answer follow-up questions, select/upload photos, then Apply draft. Review the private page before publishing through the existing website review flow. A failed model request preserves your message and proposal.
- Start an MCP client with command `node`, arguments `--import`, `tsx`, `backend/mcp.ts`, and this repository as its working directory. `npm run editor:mcp` also starts it, but clients should invoke Node directly to avoid npm banners on stdout. Set `TRICO_MCP_ORIGIN` to the local site origin if needed. Open the URL printed to stderr, sign in, reopen that URL, enter edit mode, compare the request ID, and approve. Revoke from the same panel. Pending requests expire after five minutes; approved credentials expire after fifteen and require the original login session to remain valid. Reconnect after expiry.
- Use `trico_editor` to inspect Property Management, read `property-management.leases.items`, preserve its current revision and IDs, validate a hidden lease using the collection's starter item, and save supplied answers. Ask the returned validation questions, use managed media upload/confirmation, then return the preview path. Publication and deployment are unavailable to MCP. No remote MCP listener or extra Docker stack is created.
