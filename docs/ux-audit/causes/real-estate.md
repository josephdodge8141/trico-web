Source audit of [the Real Estate screenshots and seven scores](../2026-10-05-public-pages.md#real-estate). The screenshot pass measured the rendered page; it did not verify inquiry delivery or keyboard tab behavior. TriCo's `MarketingLayout`, `Card`, layout helpers, and DS-21 theme preset are byte-identical to the current `fullstack-ts` files. TriCo's `Button` has the same variants and sizing; its only difference is the export list. Thus the shared library provides the basic styling, while the page controls the content, sequence, navigation, and component variant choices.
