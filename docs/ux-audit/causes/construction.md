**Source-backed priorities:** give Current and Completed distinct H2s and useful summaries; reduce repeated sector navigation or expose project details more directly; publish actual projects before promoting the grids as examples of work; increase the mobile menu hit area; connect both forms to a delivery path before showing success; and either implement or remove Plan Room buttons until access works. These are chiefly TriCo page/content changes, with one base Button size choice that can be overridden at the call site.
