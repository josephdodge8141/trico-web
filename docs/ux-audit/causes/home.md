# Home UX score causes

This traces the seven scores in the [public-page UX audit](../2026-10-05-public-pages.md#home) to the checked-in source. The scores describe the captured 1440px and 390px views; the code identifies likely causes, not a new usability or accessibility test. TriCo's `MarketingLayout`, `Container`, `Timeline`, and `Card` copies are byte-identical to the current fullstack-ts versions. The layout accepts caller-provided header and children; it does not choose Home's navigation, hero, section order, or content ([template MarketingLayout](/Users/Joe.Dodge/Personal/fullstack-ts/frontend/design-system/page-patterns.tsx:17), [template Container](/Users/Joe.Dodge/Personal/fullstack-ts/frontend/design-system/layout.tsx:10), [template Timeline](/Users/Joe.Dodge/Personal/fullstack-ts/frontend/design-system/layout.tsx:208), [template Card](/Users/Joe.Dodge/Personal/fullstack-ts/frontend/components/ui/card.tsx:4)).

**Attribution:** The actionable Home deductions are in TriCo's page composition and content inventory. The current evidence does not support changing fullstack-ts base components or DS-21 tokens to address them. The highest-impact correction is a mobile header navigation path, followed by shorter or progressively disclosed lower sections and earlier Contact/Careers routes.
